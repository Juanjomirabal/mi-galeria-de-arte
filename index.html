📖 Cómo crear tu token de GitHub:

  1. Entra a github.com/settings/tokens e inicia sesión
  2. Pulsa Generate new token (classic)
  3. Marca las casillas gist y repo (para guardar tus obras y publicar tu página)
  4. Pulsa Generate token y copia el código que aparece
  5. Pégalo arriba en "Token de Acceso Personal", pulsa Guardar Configuración y luego Probar Conexión
